# KceBoutique

KceBoutique est une application Android de gestion de boutiques : stocks,
ventes, achats, clients, fournisseurs, opérations Mobile Money et tontines.

L'application fonctionne hors ligne. Après connexion avec un compte Google,
les données sont sauvegardées dans le Google Drive de l'utilisateur.
